# 7.6 — Import PNG (Heightmap Grayscale)

> **Fase:** 12 · **Prioridade:** Média · **Esforço:** Baixo
> **Depende de:** Fase 4 (`.cterrain`), opcionalmente 7.4 (undo)
> **Biblioteca:** `stb_image` (já usada no projeto)

---

## Objetivo

Importar imagens grayscale (PNG, JPG) como heightmap — permitir edição externa no GIMP/Krita/World Machine e reimportação para o Caffeine.

---

## Módulo

```cpp
class HeightmapImportModule final : public ITerrainGeneratorModule {
public:
    const char* name() const override { return "Heightmap Import"; }
    void apply(TerrainGeneratorContext& ctx) override;

    std::string sourcePath;   // project-relative ou engine asset
    bool normalizeToFullRange = true;
    bool invert = false;
    f32 heightScale = 1.0f;     // multiplicador após normalizar
    f32 heightOffset = 0.0f;
};
```

---

## Fluxo

```
1. Resolver path (MeshCache::buildCandidatePaths + EditorPaths)
2. stbi_load(path) → RGBA ou grayscale
3. Converter para f32 [0,1]:
     - R channel (ou luminância) / 255
     - opcional: invert → 1 - h
     - opcional: normalize min-max para usar range completo
4. Resample se dimensões ≠ terrain.resolutionX/Z
     - bilinear resize
5. Escrever em heightmap.setNormalized(x, z, h)
```

---

## Resampling

Se PNG é 1024×1024 e terreno é 65×65:

```cpp
for (u32 z = 0; z < resZ; ++z)
    for (u32 x = 0; x < resX; ++x) {
        f32 u = x / (resX - 1);
        f32 v = z / (resZ - 1);
        f32 h = sampleBilinearFromImage(image, u, v);
        heightmap.setNormalized(x, z, h);
    }
```

Se PNG é menor que resolução do terreno → upscale com aviso no Inspector.
