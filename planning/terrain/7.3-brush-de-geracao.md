# 7.3 — Brush de Geração no Viewport

> **Fase:** 9 · **Prioridade:** Média · **Esforço:** Alto
> **Depende de:** 7.1 (módulos), 7.4 (undo), opcionalmente 7.2 (máscaras)
> **Referência:** `TerrainSculptor`, `TerrainSplatPainter`

---

## Objetivo

Permitir aplicar geradores e filtros proceduralmente com brush no viewport — como Photoshop para terreno — em vez de regenerar o heightmap inteiro.

---

## Modos de Brush

| Modo | Efeito | Módulo base |
|------|--------|-------------|
| **Noise Paint** | Adiciona noise local (fBm com raio) | `BaseNoiseModule` (região) |
| **Smooth** | Suaviza área | `SmoothFilterModule` (região) |
| **Erode** | Erosão térmica/hídrica local | `ThermalErosionModule` / `HydraulicErosionModule` |
| **Flatten** | Nivela para altura do ponto de clique | novo `FlattenBrush` |
| **Raise/Lower** | Igual sculpt mas com falloff de noise | extensão de `TerrainSculptor` |

---

## Arquitetura

```
EditorContext
├── terrainEditMode: Sculpt | Splat | Generate  ← novo
├── terrainGenBrush: Noise | Smooth | Erode | ...
├── terrainGenBrushRadius
├── terrainGenBrushStrength
└── terrainGenBrushSeed (opcional, incrementa por stroke)

SceneViewport::handleTerrainGeneratePaint()
    → TerrainGenerator::applyRegion(ctx, bounds, module)
    → TerrainCache::rebuildRegion()
```

### API região

```cpp
class ITerrainGeneratorModule {
    virtual void apply(TerrainGeneratorContext& ctx) = 0;
    virtual void applyRegion(TerrainGeneratorContext& ctx,
                             u32 minX, u32 minZ, u32 maxX, u32 maxZ) = 0;
};
```

Implementação default de `applyRegion`: só itera pixels dentro do AABB, com falloff radial a partir do centro do brush.

---

## Falloff

Reutilizar o mesmo perfil do sculpt:

```cpp
f32 falloff = 1.0f - smoothstep(radius, 0.0f, distance);
delta *= falloff * strength;
```

## UI

### Toolbar no viewport (ao lado de Sculpt / Splat)

```
[Generate ▼]  [Noise|Smooth|Erode]  Radius: ──●──  Strength: ──●──
```

### Inspector

- Quando `terrainEditMode == Generate`, mostrar parâmetros do módulo ativo (octaves, etc.)
- Checkbox **Affect Splat** — regenerar splat na região após alterar height

## Critérios de Aceitação

- [ ] Modo Generate no viewport com brush circular visível
- [ ] Noise Paint altera heightmap só na região do brush
- [ ] `rebuildRegion()` chamado — sem rebuild global
- [ ] Undo funciona por stroke (ver 7.4)
- [ ] Não interfere com modo Sculpt/Splat

---

## Riscos

- Erosão local com poucas iterações pode parecer "mancha" — expor iterations no brush
- GPU path precisa re-sync de texturas na região (splat GPU upload parcial — avaliar)
