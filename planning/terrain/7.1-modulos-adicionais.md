## Módulos a Implementar

### 1. Domain Warp (módulo separado)

Atualmente o domain warp está embutido em `BaseNoiseModule`. Extrair para módulo independente permite:

- Aplicar warp **depois** de combinar múltiplas fontes de noise
- Controlar warp apenas numa região (com máscara)
- Desligar warp no preset sem alterar o noise base

```cpp
class DomainWarpModule final : public ITerrainGeneratorModule {
    // Lê heightmap ou coordenadas, distorce sampling para módulo seguinte
    f32 strength;
    u32 seed;
};
```

**Parâmetros expostos:** `domainWarpStrength`, `domainWarpSeed` (ou reutilizar `generation.seed`)

---

### 2. Fault Lines (falhas geológicas)

Simula falhas tectónicas — deslocamento abrupto de altura ao longo de uma linha.

```
Algoritmo simplificado:
1. Definir linha (ponto A → B) ou linha aleatória com seed
2. Para cada vértice, calcular distância perpendicular à linha
3. Se dist < faultWidth: height += displacement * falloff(dist)
```

**Parâmetros:**

| Campo | Tipo | Default |
|-------|------|---------|
| `faultEnabled` | bool | false |
| `faultAngle` | f32 | 45° |
| `faultOffset` | f32 | 0.5 (posição normalizada) |
| `faultWidth` | f32 | 0.05 |
| `faultDisplacement` | f32 | 0.15 |

---

### 3. Contour Cliffs (falésias por curva de nível)

Cria margens afiadas em transições de altitude — útil para estilo stylized e terrenos com planícies + penhascos.

```cpp
if (abs(height[x,z] - height[vizinho]) > cliffThreshold) {
    // Empurrar vértice para cima ou para baixo → borda vertical
    height = quantize(height, cliffSteps);
}
```

**Parâmetros:**

| Campo | Tipo | Default |
|-------|------|---------|
| `cliffEnabled` | bool | false |
| `cliffThreshold` | f32 | 0.08 |
| `cliffSharpness` | f32 | 0.5 |
